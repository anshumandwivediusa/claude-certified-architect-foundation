# Claude Agentic SDK Cheat Sheet

## Core Components

### 1. Create Client

```python
import anthropic

client = anthropic.Anthropic(
    api_key=os.getenv("ANTHROPIC_API_KEY")
)
```

---

### 2. Create Agent

```python
agent = client.beta.agents.create(
    name="Support Agent",
    description="Handles customer support",
    model="claude-opus-5-5",
    system="You are a helpful assistant.",
    tools=[...]
)
```

---

### 3. Create Environment

```python
environment = client.beta.environments.create(
    name="demo-env",
    config={
        "type": "cloud"
    }
)
```

---

### 4. Create Session

```python
session = client.beta.sessions.create(
    agent={
        "type": "agent",
        "id": agent.id,
        "version": agent.version
    },
    environment_id=environment.id
)
```

---

### 5. Send User Message

```python
client.beta.sessions.events.send(
    session_id=session.id,
    events=[
        {
            "type": "user.message",
            "content": [
                {
                    "type": "text",
                    "text": "Check order ORD-1001"
                }
            ]
        }
    ]
)
```

---

### 6. Stream Events

```python
with client.beta.sessions.events.stream(
    session_id=session.id
) as stream:

    for event in stream:
        print(event.type)
```

---

# Important Event Types

## agent.message

Claude emits text.

```python
if event.type == "agent.message":
    print(event.content)
```

Example:

```text
Order located.
Refund requires escalation.
```

---

## agent.custom_tool_use

Claude wants your application to execute a custom tool.

```python
if event.type == "agent.custom_tool_use":
    print(event.name)
    print(event.input)
```

Example:

```text
lookup_order
{
  "order_id": "ORD-1001"
}
```

---

## session.status_idle

Session is waiting or completed.

```python
if event.type == "session.status_idle":
    print(event.stop_reason.type)
```

---

## session.status_terminated

Session ended permanently.

```python
if event.type == "session.status_terminated":
    print("Done")
```

---

# Custom Tool Flow

## Tool Definition

```python
{
  "type": "custom",
  "name": "lookup_order",
  "description": "Retrieve order details",
  "input_schema": {
    "type": "object",
    "properties": {
      "order_id": {
        "type": "string"
      }
    },
    "required": ["order_id"]
  }
}
```

---

## Execute Tool

```python
result = execute_custom_tool(
    event.name,
    event.input
)
```

---

## Return Result

```python
client.beta.sessions.events.send(
    session_id=session.id,
    events=[
        {
            "type": "user.custom_tool_result",
            "custom_tool_use_id": event.id,
            "content": [
                {
                    "type": "text",
                    "text": result
                }
            ]
        }
    ]
)
```

# Stop Reasons Cheat Sheet

## end_turn

### Meaning

Normal completion.

```python
event.stop_reason.type == "end_turn"
```

Flow:

```text
User
 ↓
Claude
 ↓
Answer Generated
 ↓
end_turn
```

---

## requires_action

### Meaning

Agent needs tool execution.

```python
event.stop_reason.type == "requires_action"
```

Flow:

```text
Claude
 ↓
Tool Request
 ↓
requires_action
 ↓
Application Executes Tool
```

Most common Agent SDK stop reason.

---

## max_tokens

### Meaning

Output limit reached.

```python
event.stop_reason.type == "max_tokens"
```

Recovery:

```python
Continue from where you stopped.
```

---

## pause_turn

### Meaning

Agent intentionally paused.

```python
event.stop_reason.type == "pause_turn"
```

Flow:

```text
Research Phase
 ↓
Pause
 ↓
Resume Later
```

---

## stop_sequence

### Meaning

Configured stop sequence encountered.

```python
event.stop_reason.type == "stop_sequence"
```

Example:

```python
stop_sequences=["END"]
```

Output:

```text
Task completed
END
```

---

## refusal

### Meaning

Safety refusal.

```python
event.stop_reason.type == "refusal"
```

Example:

```text
Request violates safety policy.
```

---

## model_context_window_exceeded

### Meaning

Too many tokens sent.

```text
History
+
Tool Results
+
Documents
+
Prompt
----------------
> Context Window
```

Fixes:

- Summarize old messages
- Trim history
- Chunk documents
- Use RAG
- Keep only relevant tool results

# Error Isolation Pattern

## Problem

Multiple tools requested.

```text
Tool A ✅
Tool B ❌
```

---

## Wrong

```text
Restart entire workflow
```

---

## Correct

Return both results:

```python
{
  "tool_use_id": "tool_1",
  "result": "success"
}

{
  "tool_use_id": "tool_2",
  "is_error": True,
  "content": "timeout"
}
```

Claude adapts.

```text
Tool A succeeded.
Tool B failed.
Retrying Tool B.
```

---

# Context Window Pattern

## Bad

```python
messages.append(all_previous_history)
```

Tokens grow forever.

---

## Good

```python
summary = """
Customer verified
KYC complete
Fraud check passed
"""

messages = [
    {
        "role": "system",
        "content": summary
    }
]
```

# Agent SDK vs Messages API

| Feature | Messages API | Agent SDK |
|----------|-------------|-----------|
| Conversation State | You manage | Anthropic manages |
| Tool Loop | You manage | Agent manages |
| Sessions | No | Yes |
| Environments | No | Yes |
| Streaming Events | Limited | Rich Event System |
| Custom Tools | Yes | Yes |
| Long-running workflows | Manual | Native |
| Stop Reason for Tools | `tool_use` | `requires_action` |
